# Statement of Intent: 零干擾學術研究筆記與課程靈感系統 (V1)

- **Outcome（目標成果）**：一個零社交干擾的 Web 雲端研究筆記系統——寫作卡關沒想法時可主動調出外部公開課程與學術資料參考，寫完後自動上傳雲端並依主題分類整理，支援跨設備閱讀與一鍵打包分享。
- **User（目標使用者）**：主要先給身為學術研究者的單一核心使用者（電腦／大平板寫作、手機／平板純淨閱讀），並能將整理好的筆記包分享給實驗室同儕或學生參考。
- **Why now（核心痛點）**：現有平台塞滿動態牆、演算法推播與按讚通知等干擾，而一般筆記軟體在寫作卡關時缺乏課程參考引導，寫完後手動分類歸檔與跨裝置整理又很費力。
- **Success（成功標準）**：寫筆記沒想法時不必離開畫面去外部搜尋分心；寫完存檔即自動整理歸類完成，換台設備打開就能順暢閱讀，需要分享時能一鍵打包送出。
- **Constraint（關鍵限制）**：定位為個人／小圈子可快速落地的輕量 Web 系統，寫作為大螢幕優先、行動端以純淨閱讀為主，介面必須極簡且由使用者主動觸發參考資料（絕不主動推播）。
- **Out of scope（明確不做）**：不做動態牆／演算法推播／按讚通知／留言社團等任何社交功能、不做離線本機 App 或重度手機編輯、不做公開會員註冊與商業付費後台、不自建大型課程影片或 PDF 檔案託管庫。
